## 三、详细测试步骤

### 测试 1：标签页切换

```
1. 打开编辑器：http://localhost:5556/
2. 拖拽"创建商品表单"到画布
3. 点击不同的标签页：
   - 基本信息
   - 价格信息
   - 库存信息
   - 状态信息
   - 描述信息
4. 观察每个标签页的内容是否正确显示
```

**预期结果**：
- 标签页切换流畅，无卡顿
- 每个标签页显示对应的字段
- 字段布局整齐美观

---

### 测试 2：表单验证

```
1. 使用"创建商品表单"
2. 点击"创建"按钮（不填写任何字段）
3. 观察验证错误提示
4. 填写商品名称
5. 再次点击"创建"
6. 观察剩余的验证错误
7. 依次填写所有必填字段
8. 点击"创建"
9. 观察是否提交成功
```

**预期结果**：
- 未填写必填字段时显示错误提示
- 错误提示清晰明确
- 填写所有必填字段后可以提交

---

### 测试 3：模式切换

```
1. 拖拽"创建商品表单"到画布
2. 观察按钮显示（"创建"、"重置"）
3. 选中组件，在属性面板中切换模式为"编辑模式"
4. 观察按钮变化（"保存"、"重置"）
5. 切换模式为"查看模式"
6. 观察字段状态（禁用）和按钮（"关闭"）
```

**预期结果**：
- 创建模式：字段可编辑，按钮显示"创建"
- 编辑模式：字段可编辑，按钮显示"保存"
- 查看模式：字段禁用，按钮显示"关闭"

---

### 测试 4：初始值加载

```
1. 拖拽"编辑商品表单"到画布
2. 观察字段是否填充了初始值
3. 检查各个字段的值是否正确：
   - 商品名称：时尚运动鞋
   - 商品货号：PRODUCT001
   - 价格：269
   - 库存：100
   - 品牌：时尚运动
   - 分类：鞋子
```

**预期结果**：
- 所有字段正确显示初始值
- 开关组件显示正确状态
- 下拉选择框显示正确选项

## 五、常见问题排查

### 问题 1：组件不显示

**可能原因**：
- UMD 文件未正确加载
- Meta 文件未正确加载

**解决方案**：
1. 打开浏览器控制台
2. 检查是否有加载错误
3. 刷新页面重试

### 问题 2：标签页不显示

**可能原因**：
- showBasicInfo 等属性设置为 false

**解决方案**：
1. 选中组件
2. 在属性面板中检查"标签页显示控制"
3. 确保所有开关都打开

### 问题 3：表单验证不生效

**可能原因**：
- 表单字段未正确绑定

**解决方案**：
1. 检查表单字段是否正确渲染
2. 检查表单验证规则是否正确设置
3. 刷新页面重试
