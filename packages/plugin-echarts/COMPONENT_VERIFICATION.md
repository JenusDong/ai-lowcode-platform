## 🚀 如何在低代码编辑器中使用

### 方法1: 从组件面板拖拽

1. 打开低代码编辑器
2. 左侧组件面板 → **"图表组件"** 分类
3. 展开 **"ECharts图表"** 分组
4. 找到 **"ECharts 地图"** 组件
5. **拖拽到画布**即可使用

### 方法2: 从Snippets快速创建

1. 在画布或组件面板搜索 **"地图"**
2. 选择以下任一模板：
   - **分省填色地图** - 最常用，适合数据分布展示
   - **散点地图** - 适合城市点位展示
   - **动态散点地图** - 带动画效果，适合重点标注
   - **热力图地图** - 适合密度分析
   - **流向线地图** - 适合路径/流向展示

### 方法3: 代码模式使用

在代码编辑区直接输入：
```json
{
  "componentName": "EChartsMap",
  "props": {
    "mapType": "china",
    "visualType": "fillColor",
    "theme": "dark"
  }
}
```
