## 🚀 快速开始

### 1️⃣ 在低代码编辑器中创建大屏

#### **步骤1：创建新页面**
1. 打开低代码编辑器
2. 创建新页面，命名为"行业数据大屏"
3. 设置页面背景色：`#0a1a3a`（深蓝色）

#### **步骤2：添加地图组件**
1. 左侧面板 → 图表组件 → 地图可视化
2. 拖拽"ECharts 地图"到画布中央
3. 设置样式：
   - 宽度：`100%`
   - 高度：`600px`

#### **步骤3：添加其他图表组件**
在地图周围添加：
- 左侧：ECharts 饼图、ECharts 柱状图
- 右侧：ECharts 折线图、ECharts 雷达图
- 底部：ECharts 面积图

## 🔧 高级配置

### **地图交互配置**

```json
{
  "roam": true,
  "zoom": 1.2,
  "center": [104, 35],
  "enableDrillDown": true,
  "showTooltip": true,
  "showLegend": true
}
```

### **地图可视化类型**

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| `fillColor` | 分省填色 | 人口分布、GDP、销售数据 |
| `scatter` | 静态散点 | 城市点位、门店分布 |
| `effectScatter` | 动态散点 | 实时数据、重点城市 |
| `heatMap` | 热力密度图 | 人流热力、活跃度 |
| `lines` | 流向线动画 | 物流路径、迁徙路线 |

## 💡 最佳实践

### **1. 性能优化**
- 地图数据控制在500个点以内
- 使用 `lazyUpdate: true`
- 避免频繁更新数据

### **2. 数据钻取**
```javascript
// 点击省份后加载详细数据
onRegionClick: (params) => {
  const provinceName = params.name;
  loadProvinceData(provinceName);
}
```

### **3. 响应式设计**
```javascript
// 监听窗口大小变化
window.addEventListener('resize', () => {
  chartInstance.resize();
});
```

### **4. 数据更新**
```javascript
// 定时更新数据
setInterval(() => {
  fetchLatestData().then(data => {
    chartInstance.setOption({
      series: [{ data: data }]
    });
  });
}, 5000);
```

## 📞 技术支持

### **常见问题**

**Q: 地图不显示？**
A: 检查网络连接，确保能访问地图GeoJSON数据

**Q: 图表样式不统一？**
A: 使用统一的主题配置，参考上面的配色方案

**Q: 数据更新不生效？**
A: 确保 `notMerge: false`，使用正确的数据格式
